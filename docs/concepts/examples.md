# Примеры применения концептов (черновые кейсы)

1) Локальная образовательная сеть (Distributed cognitive network)
- Контекст: небольшая сеть локальных учебных групп и онлайн-курсов.
- Применение: общий репозиторий курсов, механизмы peer-review материалов, протоколы верификации знаний.
- Результат: быстрее проверяемый и повторно используемый контент, снижение дублирования усилий.

2) Дизайн пространства встречи (Cultural programming)
- Контекст: сообщество организует ежемесячные офлайн‑встречи.
- Применение: введение ритуала открытия, правило «двух микрофонов» для управления очередностью выступлений, формат обратной связи.
- Результат: более предсказуемые встречи, повышение вовлечённости и качества обсуждений.

3) Тренинг критического мышления (Basic soft freedom)
- Контекст: курс для новых участников сообщества.
- Применение: модуль по fact‑checking, практики аргументации, чек‑листы для оценки источников.
- Результат: повышение уровня аргументации в обсуждениях и снижение распространения недостоверной информации.

4) Программа личного развития (Passion for self‑management)
- Контекст: поддержка членов сообщества в планировании проектов и жизни.
- Применение: цикл менторских сессий, шаблоны планов, финансовые ориентиры.
- Результат: рост числа самостоятельных инициатив и уменьшение зависимости от внешних инструкций.
